## 01 我在火里睡了一觉 ★现有正文

**一句话**：他在谷仓大火里睡觉，被七个邪教徒吵醒，一句"闭嘴"把他们连名字一起抹了。十岁的阿尔萨斯举着木剑冲进来，他打了个哈欠："有吃的吗？"

**开局**：火里睡觉 → 教徒变鸡 → 全村复活、麦田秒回 → 阿尔萨斯给他起名"烬"。

**主线**：王城 → 达拉然 → 铁炉堡 → 黑龙 → 银月城 → …… → 虚空 → 结局。十五卷，见 `记忆区/01`。

**女主**：佳莉娅（守夜人）、吉安娜（变数）、希尔瓦娜斯（无名者）、诺拉（阿烬）。

**爽点**：火不烧他、名字删除、面包变蛋糕、椅子变猪、龙变猫。

## 02 开局删除燃烧军团

**一句话**：恶魔大军从天而降，他抬头看了一眼，说"吵"，军团没了，连云都补好了。

**开局**：王城宴会上恶魔如雨落下，他筷子都没放；基尔加丹亲至，被他变成一只苍蝇弹进酒杯。

**主线**：一章删一个更大的：先锋 → 基尔加丹 → 阿克蒙德 → 军团母舰 → 萨格拉斯 → 虚空。

**女主**：吉安娜（记录"被删掉的历史"）、希尔瓦娜斯（只服强者）、奥妮克希亚（吓得来投诚）。

**爽点**：越打越轻松，一章一个灭世级。

## 03 我把阿尔萨斯养成了龙傲天

**一句话**：他懒得动手，把所有好东西塞给阿尔萨斯。三个月后，十岁的王子一剑劈开了演武场。

**开局**：熔了全王宫的剑，铸成一把"随便"；阿尔萨斯随手一挥，演武场从中间裂开；乌瑟尔跪了。

**主线**：铸剑 → 速成 → 单杀恶魔领主 → 单杀黑龙 → 师徒切磋（输得体面）→ 阿尔萨斯自己收徒。

**女主**：吉安娜（她喜欢变强的王子）、佳莉娅（怕弟弟被宠坏）、希尔瓦娜斯（只服强者）。

**爽点**：主角躺赢，王子起飞，读者爽两遍。

## 04 神明的日常就是打脸

**一句话**：他是王子的伴读，每天有人来打脸，他每天打回去，而且每天换一种打法。

**开局**：贵族骂他"野种"，头发一夜长到拖地；审判官来验他，圣光变成会唱歌的彩灯；刺客的刀变成一条活鱼。

**主线**：贵族 → 教会 → 达拉然 → 铁炉堡 → 黑龙 → 精灵 → 审判庭 → 军团 → 全世界一起来。

**女主**：佳莉娅（收拾残局）、莉薇娅（写成书）、诺拉（给挨打的人送面包）。

**爽点**：一章一个笑点，短平快。

## 05 我把魔兽改成了单机

**一句话**：他把城墙改成奶油蛋糕，全城吃了三天；又把瘟疫改成"只会让人放屁"的病。

**开局**：奶油城墙 → 放屁瘟疫 → 巫妖王的头盔改成夜壶。

**主线**：一路改，世界一路崩，最后他嫌麻烦，干脆重开一局。

**女主**：吉安娜（研究"世界编辑器的语法"）、莉薇娅（记录被改掉的历史，越记越崩溃）。

**爽点**：脑洞最大，画面最离谱。

## 06 我在冰冠堡垒有套房

**一句话**：他嫌王城吵，搬进冰冠堡垒，把巫妖王赶去睡客厅。第二天，天灾军团排队给他铺床。

**开局**：一脚踹开门"这房子我租了"；巫妖王被拍成头盔挂件；天灾排队烧水做饭。

**主线**：各方来讨伐，发现巫妖王在给他端茶；最后把堡垒改成全宇宙最贵酒店。

**女主**：希尔瓦娜斯（来复仇，被留下吃火锅）、吉安娜、奥妮克希亚（来抢房，成了租客）。

**爽点**：反派老家变喜剧现场。

## 07 我的宠物是死亡之翼

**一句话**：灭世黑龙从天而降，他伸手摸了摸龙头："乖。"下一秒，黑龙变成一只黑猫。

**开局**：收猫 → 取名"小黑" → 骑着它去王城吃早饭，把早点摊老板吓晕。

**主线**：四大守护巨龙上门要人，全被收；龙眠神殿变成宠物店。

**女主**：奥妮克希亚（她爹成宠物，她成了"宠物家属"）、佳莉娅（负责取名）。

**爽点**：骑龙上班，画面感最强。

## 08 我把燃烧军团收编了

**一句话**：恶魔大军降临，他摆出一张桌子："招人，包吃住，五险一金。"

**开局**：基尔加丹不服，被分配去扫厕所；阿克蒙德嘴硬，被派去前台。

**主线**：军团改成公司 → 绩效考核 → 恶魔内卷 → 萨格拉斯来面试。

**女主**：奥妮克希亚（人事总监）、吉安娜（财务）、希尔瓦娜斯（安保队长）、诺拉（食堂）。

**爽点**：职场梗，笑点最密。

## 09 全知全能的我只想摆烂

**一句话**：天塌了，他把被子往头上一蒙："明天。"国王亲自来请，他翻个身："带饭了吗？"

**开局**：地震被他一翻身压停；国王来求，他问"管饭吗"；佳莉娅红着眼睛来，他瞬间坐起来："谁欺负你？"

**主线**：一路摆烂，一路被逼出手，每次出手都是名场面。

**女主**：佳莉娅（唯一能叫醒他的人）、诺拉（用面包叫）、吉安娜（用算术叫）、希尔瓦娜斯（用箭叫）。

**爽点**：反差萌，最轻松。

## 10 神级钓鱼佬

**一句话**：他在湖边钓鱼。第一天钓上来一条会说话的鱼，鱼说"我是海神"，他说"红烧还是清蒸"。

**开局**：钓上海神 → 钓上死亡之翼 → 钓上一把会说话的剑。

**主线**：钓上来的东西越来越大，湖边越来越热闹，全世界的强者排队来"被钓"。

**女主**：温蕾萨（来钓鱼，被钓上来）、希尔瓦娜斯（来查湖，坐下一起钓）、诺拉（把钓上来的做成菜）。

**爽点**：悠闲荒诞，最适合做封面。

## 11 王城万能杂货铺

**一句话**：他的杂货铺什么都卖、什么都能修。价格不是钱，是"讲个笑话""陪我吃顿饭"。

**开局**：农妇拿半袋麦子换一场雨；王子拿木剑来修，附赠"一剑劈山"；贵族拿金币买长生，他说"讲个笑话"。

**主线**：店铺成了王城情报中心，姑娘们天天来；最后开成万界连锁。

**女主**：诺拉（隔壁面包店）、佳莉娅（来买"一个不被打扰的下午"）、吉安娜（来买"一个答案"）。

**爽点**：温情又爽，最耐看。

## 12 全知全能者的美食旅行

**一句话**：他为吃遍艾泽拉斯而旅行，每到一个地方顺手解决灾难——只因为"吃顿好的得有个好环境"。

**开局**：嫌矮人面包硬，把整座山改成面包窑；到银月城，把酒变成仙酿；到诺森德，把天灾的冰化成糖水。

**主线**：一卷一个地区、一种菜、一场灾难。

**女主**：诺拉（同行厨师）、希尔瓦娜斯（带路）、莫伊拉（用锤子砸硬壳）。

**爽点**：轻松，最容易写长。

## 13 我在艾泽拉斯当客服

**一句话**：全世界的祈祷变成工单落到他桌上。第一天上班，他收到三十万张。

**开局**：一个响指全清 → 闲得发慌 → 给自己开 VIP 通道，姑娘们的工单优先。

**主线**：奇葩工单 → 法师投诉"神迹不合规" → 军团集体下工单 → 最后一张工单来自"世界"。

**女主**：薇拉（教会对接）、佳莉娅（王室对接）、吉安娜（技术顾问）。

**爽点**：单元剧，节奏最好。

## 14 我不想当王，王位给你

**一句话**：他一天统一七国，然后宣布"我不管"，把王冠扣在十岁的阿尔萨斯头上。

**开局**：加冕典礼上把王冠扣给王子；阿尔萨斯哭着说"我才十岁"；他说"我也才十二"。

**主线**：国库危机 → 各国来使 → 军团来犯，阿尔萨斯御驾亲征 → 王子真的成了王。

**女主**：佳莉娅（摄政）、吉安娜（财政）、希尔瓦娜斯（外交）、莫伊拉（工业）。

**爽点**：朝堂喜剧，阿尔萨斯最出彩。

## 15 我在魔兽当导演

**一句话**：他把世界当剧本，给阿尔萨斯安排了"英雄剧本"，结果阿尔萨斯第一场戏就忘词。

**开局**：写好剧本 → 演员不听话 → 他改剧本，世界跟着改。

**主线**：法师发现"世界有剧本" → 黑龙想改自己的结局 → 军团集体罢演 → 他撕了剧本。

**女主**：莉薇娅（编剧助理，偷偷改台词）、吉安娜（拒绝按剧本爱上谁）、希尔瓦娜斯（一出场就抢戏）。

**爽点**：元叙事，台词最好玩。

## 16 开局一座神国

**一句话**：他在荒原上说了一句话，地上立起一座钟楼。三年后，这里是三十万人的神国。

**开局**：一句话涌出一口井 → 一句话立起钟楼 → 定下第一条规矩："这城里不许有人跪着说话"。

**主线**：第一场饥荒 → 王国封锁 → 黑龙来投资 → 瘟疫难民潮 → 神国升空。

**女主**：诺拉（城的胃）、艾达（城的盾）、莫伊拉（城的骨）、莉薇娅（城的记忆）。

**爽点**：种田建设，越建越大。

## 17 全知全能的我在睡觉，别吵

**一句话**：他在王城地下睡了一百年。醒来发现城成了废墟、天灾横行，他打了个哈欠，全城复原，然后回去接着睡。

**开局**：百年后醒来 → 一巴掌复原全城 → 躺回去继续睡。

**主线**：一世一个时代，每次醒来一巴掌；最后有人不让他睡了。

**女主**：每一世都有姑娘等他醒来；诺拉每一世都在开面包店。

**爽点**：高概念，有爽有泪。

## 18 我把所有女主都救了

**一句话**：他提前十年把所有人的悲剧都改了：希尔瓦娜斯不死、塔蕾莎不死、佳莉娅不嫁、诺拉不烧。

**开局**：救人 → 被救的人一脸懵"我本来会死？" → 他理直气壮"是啊，我改的"。

**主线**：被救的人不适应 → 她们想证明自己 → 她们联手"反抗"他 → 她们自己救了自己。

**女主**：全员，一人一条"被救之后"的线。

**爽点**：全员 HE，最治愈。

## 19 全知全能者的退休生活

**一句话**：他退休了，在湖边盖了间小屋。第二天世界末日，众神排队请他返聘，他开价："管饭，别吵，让我睡午觉。"

**开局**：盖屋钓鱼 → 天裂了 → 众神排队 → 他开条件。

**主线**：修天 → 捞月亮 → 劝架 → 带娃 → 收拾自己一千年前留下的烂摊子。

**女主**：诺拉（房东，负责管饭）、佳莉娅（雇主）、吉安娜（技术顾问）。

**爽点**：退休梗，轻松好笑。

## 22 我教阿尔萨斯一招秒神

**一句话**：他教阿尔萨斯"一句话法则"。第一课："把你的剑忘掉。"阿尔萨斯一剑劈开了山。

**开局**：忘剑 → 劈山 → 第二课"让敌人忘记怎么呼吸"，一口气秒了恶魔领主。

**主线**：三课 → 偷师的人越来越多 → 阿尔萨斯单杀黑龙 → 师徒切磋 → 阿尔萨斯自己收徒。

**女主**：吉安娜（学得比王子快）、佳莉娅（怕弟弟走火入魔）、希尔瓦娜斯（只服强者）。

**爽点**：王子最帅，成长最快。

## 23 世界末日？我先睡个午觉
