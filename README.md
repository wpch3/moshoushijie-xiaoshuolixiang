# 《魔兽世界：我在火里睡了一觉》

一个真正的全知全能者，在谷仓大火里睡了一觉，被吵醒，顺手把七个邪教徒从世界上抹了。然后他捡了个十岁的王子，开始玩。

**不压战力。没有代价。没有苦战。**
阿尔萨斯是他最好的兄弟——两个人一起偷蛋糕、一起被骂、一起给贵族下绊子。
