# 《魔兽世界：成年之前》

黑门前四年，冬。洛丹伦下了三天三夜的雪。

王后难产。长子生下来没有呼吸。国王抱过他，给他起了名字，刻进册子：**洛恩·米奈希尔，长子，死胎。**

三天后，那个孩子睁开了眼睛。

王后摸他的胸口，摸不到心跳。她把他抱起来，说了一句："我不管你是谁。你是我的。"

同一夜，天裂了。五色巨龙来了四位，万神殿的眼睛来了，虚空来了一个没有脸的东西。它们不看国王，它们要看那个孩子。

观测者说：归零协议已经写好了，只等他"不在了"就发。唯一的例外——他以孩子形态出现时，成年之前不发。

泰瑞纳斯当场说："那我改律法。"

观测者说：已记录。然后提醒他：没用。我复核的不是律法，是他愿不愿意留下。

**所以国王接下的不是"养大救世主"，是"让这个世界通过面试"。**

**不压战力。没有代价。没有苦战。**
他和阿尔萨斯是双胞胎兄弟，但不是亲生的。这件事，只有王后一个人知道。
