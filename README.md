# 《魔兽世界：他们偷走了二王子》

洛丹伦的二王子被邪教徒偷走了，绑在谷仓里烧给湖底的东西。
火不敢烧他，他睡到一半被吵醒，一句"吵"，把七个教徒连名字一起抹了。
十岁的阿尔萨斯提着木剑骑马赶来，喊的是——"哥"。

**不压战力。没有代价。没有苦战。**
他们是双胞胎兄弟，但不是亲生的。这件事，只有王后一个人知道。
